# QuantRadar — موتور سیگنال‌دهی و ارزیابی استراتژی (Pocket Option و Olymp Trade)

نسخه فوق‌سبک پایتون (**FastAPI + asyncio + WebSockets + aiosqlite + NumPy**) برای اجرای ۲۴ ساعته روی ویندوز سرور یا سیستم شخصی.

---

## ۱. روش نصب و اجرا روی ویندوز

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
python main.py
```

سپس مرورگر را روی `http://localhost:8000` باز کنید.

---

## ۲. روش اتصال به Pocket Option / Olymp Trade و تست اتصال (SSID)

برنامه در حالت پیش‌فرض **کاملاً متوقف و قطع (Disconnected)** است و تا زمانی که اتصال را برقرار نکنید و ارزهای دلخواهتان را انتخاب نکنید، هیچ تستی انجام نمی‌دهد.

1. با حساب **دمو (Demo)** وارد سایت **Pocket Option** یا **Olymp Trade** در مرورگر کروم شوید.
2. کلید **F12** (DevTools) را بزنید → وارد تب **Network** شوید → فیلتر **WS** را انتخاب کنید و یک‌بار صفحه را رفرش کنید.
3. روی اتصال WebSocket کلیک کنید → تب **Messages** → فریم `42["auth",{"session":"..."}]` (در پاکت آپشن) یا کوکی `ssid` (در المپ ترید) را کپی کنید.
4. در داشبورد QuantRadar روی **اتصال به بروکر (SSID)** کلیک کنید، بروکر را انتخاب کنید، SSID را جای‌گذاری کنید و روی دکمه **تست اتصال** بزنید تا اتصال واقعی و پینگ (ms) قبل از ذخیره تأیید شود.
5. پس از تأیید اتصال، روی **ذخیره و اتصال** کلیک کنید.

---

## ۳. انتخاب ارزها، تایم‌فریم و حالت اسنایپر دقیق

- در نوار بالای داشبورد، **فقط** ارزهای موردنظرتان (مثلاً ۱ تا ۳ جفت‌ارز) و تایم‌فریم دلخواه (مثلاً فقط `5m` یا فقط `1m`) را انتخاب و روی **اعمال محدوده تست** کلیک کنید.
- اگر هیچ ارزی انتخاب نشده باشد یا دکمه **توقف همه** را بزنید، موتور هیچ سیگنال یا تستی اجرا نمی‌کند.
- هر ۱۰ استراتژی با **فیلتر دقت بالا (High-Precision)** و فاصله اطمینان زمانی (Cooldown) تنظیم شده‌اند تا به‌جای ارسال سیگنال در هر دقیقه، فقط روی ستاپ‌های دقیق و تأییدشده سیگنال صادر کنند.
- پس از ارزیابی در حالت **تست سایه (Shadow Lab)**، استراتژی‌های برتر را در تب **آزمایشگاه استراتژی** تیک **Active** بزنید و حالت بالای صفحه را به **اسنایپر واقعی (Active Sniper)** تغییر دهید.
